# Field-days are keyed by (field_id, date) and a rerun overwrites that date

_Status: archived 2026-11-21 with the satellite example ([ADR 0021](0021-archive-the-satellite-example.md)). It describes code under `archive/v1-satellite/`, not the supported build._

Late-arriving Scenes are another run of the same date, not a new version. Missing rows become observed or cloudy. There is no SCD2 or as-of history in this portfolio.
